
# Global Olympic Sports Performance Analysis 🏅

An interactive data visualization project exploring Olympic sports performance, medal achievements, athlete participation, and regional trends using Tableau Public and Flask.

## 📊 Project Overview

This project presents Olympic sports data through interactive Tableau dashboards embedded in a Flask web application.

The goal is to make sports performance data easier to explore and compare across countries, regions, sports, and Olympic editions.

## ✨ Features

- Interactive Tableau dashboards
- Top 10 countries by medal achievements
- Medal breakdown by country
- Medal performance trends over time
- Medal efficiency comparisons
- Regional medal performance
- Summer vs. Winter Olympic comparisons
- Athlete participation by sport
- Athlete gender distribution
- Responsive Flask website layout

## 🛠️ Technologies Used

- Python
- Flask
- Tableau Public
- HTML
- CSS
- Git and GitHub

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/aeraa1725-bot/olympic-performance-dashboard.git
   ```

2. Navigate to the project directory:

   ```bash
   cd olympic-performance-dashboard
   ```

3. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Start the Flask application:

   ```bash
   python app.py
   ```

5. Open http://127.0.0.1:5000 in your browser.
